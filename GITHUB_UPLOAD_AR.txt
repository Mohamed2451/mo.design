طريقة رفع النسخة الجديدة إلى GitHub Pages

1- افتح المستودع: https://github.com/Mohamed2451/mo.design
2- احتفظ بنسخة احتياطية أو أنشئ فرعًا جديدًا قبل استبدال الملفات.
3- فك الضغط على هذا الملف عندك.
4- ارفع *محتويات* المجلد المستخرج (index.html و assets و projects و services و .github...) مباشرة في جذر المستودع؛ لا ترفع ZIP نفسه ولا تضع الملفات داخل مجلد إضافي.
5- نفّذ Commit changes وانتظر GitHub Actions ليتم النشر.
6- راجع الصفحة على الرابط: https://mohamed2451.github.io/mo.design/
7- امسح كاش المتصفح أو جرّب نافذة خاصة عند ظهور النسخة القديمة.

ملاحظات مهمة:
- بيانات آراء العملاء المعروضة أمثلة توضيحية وغير موثقة (حتى لو بها 5 نجوم). بدّلها بشهادات حقيقية قبل استخدامها لأغراض تسويقية.
- أرقام الإنجازات أُظهرت بحسب الأرقام التي طلبتها؛ تأكد من دقتها قبل نشر الموقع للعامة.
- إعداد Supabase مطلوب لتفعيل لوحة الإدارة المركزية وتخزين طلبات العملاء.
- الموقع المنشور حاليًا لم يُعدّل تلقائيًا من هذا الملف.
